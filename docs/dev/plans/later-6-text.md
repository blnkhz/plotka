# LATER-6: Single-stroke text

Decided with the user (2026-11-02): Hershey fonts; SVG `<text>` is drawn with them, with a note.

- **Font data**: six styles from the Usenet Hershey distribution (futural → Sans, futuram → Sans
  bold, timesr → Serif, timesi → Serif italic, scripts → Script, gothiceng → Gothic), glyphs for
  ASCII 32–126 kept as their .jhf records in `text/hershey-data.ts` (38 KB), generated by a
  script; credited in the file, THIRD_PARTY_NOTICES and the guide. Its use restriction only asks
  for the acknowledgements and not to convert it to the NTIS format.
- **Layout** (`text/text.ts`): size = capital height (Hershey capitals: 21 units), lines on
  '\n' at 32 units × line spacing, letter spacing in mm, left / center / right. Accents are
  dropped (NFD), a few typographic characters mapped, anything else drawn as "?".
- **Text layers**: `TextItem`s in the project; each is a layer (`text-<id>`, `layer.text`) of
  the document, made by `withTexts`. They're already on the paper: transforms and the page fit
  skip them, and they don't count toward the artwork's size. Everything else (overrides, Arrange,
  speed, plot checkbox, passes) treats them as layers; ✕ deletes the text (undoable). Text works
  with no file open (an empty paper-sized document). Saved with projects, in undo and autosave.
- **SVG text**: `<text>` with `<tspan>`s, placed by x / y / dx / dy and text-anchor, font size
  (px, pt, mm, em, %) with capitals at 70% of it; style from font-family / weight / style (serif,
  script, gothic, else sans; bold, italic); color from fill (or stroke).
