# Keyboard shortcuts

| Keys         | Does                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------- |
| ⌘O           | Open an SVG, picture, 3D model or project                                                          |
| ⌘S           | Save the project                                                                                   |
| ⇧⌘S          | Save the project under a new name                                                                  |
| ⌘E           | Export what will be plotted as SVG                                                                 |
| ⇧⌘E          | Export the toolpath as JSON                                                                        |
| ⌘Z           | Undo                                                                                               |
| ⇧⌘Z          | Redo (on Windows, Ctrl+Y too)                                                                      |
| F            | Fit the page in the preview                                                                        |
| Space + drag | Move the view in the preview                                                                       |
| Space        | Pause or resume a plot                                                                             |
| U            | Pen up (when not plotting)                                                                         |
| D            | Pen down (when not plotting)                                                                       |
| Delete       | Remove the selected shapes on the doodle pad                                                       |
| Enter / Esc  | Keep / cancel a new layer name                                                                     |
| ⌘? or F1     | Help                                                                                               |
| Esc          | Close the start screen, help, or the doodle, image or 3D model window; finish placing fill centers |

Single-letter keys don't work while typing in a text box.
